# Tasks 台账

`docs/tasks/` keeps lightweight, independently traceable records for Octo requirements, investigation, implementation, and verification. It records implementation facts and proof boundaries; it is not a replacement for Meegle.

## Modules

- `cli/`: local Octo CLI, agent API contracts, bundled agent skills, and installation flows.

Each module owns its own README and dated task records. Keep runtime proof distinct from static tests and local builds.

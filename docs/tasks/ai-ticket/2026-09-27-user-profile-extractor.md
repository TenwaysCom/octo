# User profile extractor 设计及双用户验证

## 目标与范围

按用户最新要求，输出 JSON 中的性格特点、沟通特点、需求特点及其证据；去除服务概况、历史方案列表、当前行动建议和沟通草稿。性格特点以有证据的场景行为倾向表达。设计增量更新并验证两个用户的首次提炼及后续变更。交付设计、可执行验证原型及验证证据；不新增线上表、路由、自动调度或远端 wiki 发布。

## 验收标准

- [x] v2需求：JSON只含三类特征与证据/限制，提示词和校验器同版；旧版输出不得复用。
- [x] 新结构下增量设计与原型涵盖新增、更正、删除、改归属、窗口移出、无变化、失败与并发失效；调度和真实事务未集成。
- [ ] 两个用户完成首次提炼及增量验证，明确真实数据/模型与合成规则测试边界。
- [ ] 检查引用、重复证据去重、偏好反例与错误旧结论撤回；内容语义人工复核。

## 决策

当前边界：本轮用户修改提炼范围，已恢复本地设计与原型修订。真实模型外发仍未授权（此前自动审批拒绝业务历史及可能残留第三方姓名外发）；新增性格/沟通特点还需核对需求人消息角色并补充对应原文。完整双用户验证需该证据范围与既有智谱 `glm-5.3-flash` 外发授权后执行。未发送模型请求，无活动模型进程可等待。

当前决定：三类特征分别为 personality、communication、needs；仅输出场景化、有来源的观察，保留反例，证据不足留空。两张独立工单只是重复观察门槛，不是统计置信度。旧v1需求的服务背景/处理经验提炼范围标为 superseded，旧16项测试不能直接证明新结构已验证。

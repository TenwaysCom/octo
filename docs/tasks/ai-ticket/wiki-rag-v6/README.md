## 验证、隔离与样本边界

- 组合候选：178项测试，7文件通过，包含真实reader／service强制错选检查及Wiki QA／Shadow既有消费回归。G单项169项、6文件通过；R阶段定向92项、3文件通过。重复覆盖不相加当独立测试数。R、G、RG三个隔离候选均通过TypeScript build。
- 新增机制覆盖元数据／其他段落不能当原文、未选中来源、明确错误签名冲突、原始预算失败不能回退、后续未解决与Shadow排除；既有路径、符号链接、取消、环境、来源缺失及后续纠正回归保持。
- R使用reader内部可选相关性复核能力，真实reader在service入口重新判断；既有mock／旧reader没有这项能力时维持原行为，不能视为具有R防护。没有新增HTTP接口／UI。证据关联诊断通过显式deps回调，未把源正文写入日志。
- 原65题不再算独立；新12事件在代码实现前冻结，正例按既有事实及来源核对，负例只标注明确错误的配对。未标注其他页面不自动判错。新6个正例涉及混合语言来源，但未新增独立的成功技术锚点回退；样本量和类型不足以证明一般跨语言改善。[来源核对](primary-audit.json)仅保存路径、哈希及边界。
- 三轮开发仅使用旧65题，R旧正例34→39→40，规则细化和测试语义变化记录于[开发记录](development-decisions.md)。锁定最终候选后才运行新留出一次；没有用首次独立失败重调规则。
- 所有结果基于冻结模型提取／问题文本，不等于未经提取的原始用户措辞。沿用现有脱敏，旧Q24输入限制见v5报告。缺关键词的旧题没有从gold注入扩词。
- 原始知识和平台日志没有打包进入任务文档；隔离快照保留`/tmp/octo-wiki-rag-v6`，临时目录清除后须恢复相同哈希才能复跑。取样用的私有日志临时文件已清理。
- 单元及条件mock不证明真实Top5或答案正确率；未执行live E2E、并发／性能或部署验证。旧案例、draft、unknown、unresolved未被升级为当前修复。

# Meegle Sprint 时间列最小宽度

## 目标

避免 Meegle Sprint 详情工作项表格的“当前工作时长”和“更新时间”列被压缩。

## 验收标准

- [x] 当前工作时长列最小宽度为 132px。
- [x] 更新时间列最小宽度为 148px。
- [x] 分组与未分组的 Sprint 工作项表格均生效。
- [x] FE 构建和样式选择器静态检查通过。

## 范围与决策

- 仅调整 Meegle Sprint 详情表格；不改变列内容、排序、数据请求或普通工作项列表。
- 通过稳定列键定位可配置列，空间不足时继续由现有表格容器横向滚动承接。
